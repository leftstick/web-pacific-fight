# 光之战士 · 像素对决

致敬 90 年代街机格斗的 **2D 像素风横版对战**：6 名原创「光之战士」对阵 10 只原创怪兽。
零框架、零依赖、零构建，全部美术与音效在运行时程序化生成。

- 内部分辨率固定 **640 × 360**，整数倍放大 + letterbox，`image-rendering: pixelated`
- 逻辑帧率固定 **60Hz**（固定步长 + accumulator），粒子上限 200
- 支持键盘、鼠标与手机横屏触屏（虚拟摇杆 + 三键布局，可拖动自定义）
- 全中文界面，5×7 点阵字体 + 系统中文像素化排版

## 运行

项目使用原生 ES Module，浏览器不允许 `file://` 直接加载模块，需要静态服务器：

```bash
cd web-pacific-fight
python3 -m http.server 8000
# 打开 http://localhost:8000
```

部署 GitHub Pages：把仓库根目录设为 Pages 发布源即可，无需构建。

## 操作

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 / 跳跃 / 蹲下 | `A` `D` / `W` / `S` | 左侧虚拟摇杆（8 向） |
| 轻击 | `J` | A |
| 重击 | `K` | B |
| 必杀 | `L` | C |
| 超必杀 | `I`（能量满或血量 ≤25%） | 蹲 + C |
| 确认 / 开始 | `Enter` / `空格` | 点击屏幕 |
| 返回 / 暂停 | `Esc` / `Backspace` | 右上角暂停 |

- 按住「后」防御，按住「下 + 后」蹲防；下段攻击必须蹲防，跳跃攻击必须站防，投技不可防。
- 蹲 + 重击 = 蹲重（下段击倒），空中 + 重击 = 跳重。
- 双击「前」前冲，双击「后」后撤（首帧 8px、前 3 帧无敌、共 18 帧）。
- 被浮空击飞后，落地前按 `J` 可受身。
- 血量 ≤25% 时可无视能量槽释放超必杀（背水一击）。
- 调试：`F1` 显示判定框（红攻击 / 蓝受击），`` ` `` 显示 FPS 叠层。
- 暂停菜单 →「调整键位」可拖动摇杆与按钮，位置保存到 `localStorage`。

## 模式

- **街机模式**：共 6 关。前 5 关从 9 只常规怪兽中随机不重复抽取，第 6 关固定两阶段 Boss「陨核巨像」。
- **自由对战**：自选英雄与怪兽，10 只全部可选。
- **训练模式**：无限时间，练习连段。

三局两胜，每回合 99 秒；血量相同时判平局并重开本回合。KO 触发 0.25 倍速慢动作与镜头推进。四档 AI 难度（反应延迟 8–14 帧）。

## 目录

```

src/main.js           固定 60Hz 主循环 + 流程状态机
src/core/             画布缩放 / 点阵字体 / 输入 / WebAudio 合成
src/data/             帧数据、6 名英雄、10 只怪兽、3 个舞台
src/art/              分部件像素组装、怪兽骨架、视差背景、粒子
src/game/             状态机、判定框、伤害结算、AI、镜头、回合流程
src/ui/               HUD、菜单界面、触屏虚拟按键
```

## 技术要点

- 数据驱动帧数据：`startup / active / recovery / damage / hitstun / blockstun / push / cancel / hitstop / meterCost`
- AABB 判定框，判定框 y 采用屏幕坐标（地面 y = 310）
- 连段递减 100/90/80/70/60%，下限 30%；浮空追打最多 3 段
- 命中停顿 6/10/12/20 帧；能量 0–100（命中 +2 / 受击 +3 / 防御 +1）
- 精灵离屏缓存（LRU 120），受击白闪使用独立全白调色板
- 三层视差舞台 + 天气层；所有特效来自固定 200 容量的对象池
- 超必杀演出：聚能环 → 横向光线 / 竖向光柱 → 冲击环 + 全屏闪白 + 震屏
