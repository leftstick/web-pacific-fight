【项目定位】
一款致敬《街头霸王 2》《真人快打》的浏览器像素格斗游戏。6 名可选角色是一组
「光之战士」变体（但绝不使用 Ultraman / 奥特曼 等官方名称与官方形象），
另有 10 只原创怪兽作为对手。核心体验：手感先行、判定严谨、手机横屏可玩。

【第一优先：技术硬约束，不得违反】
1. 技术栈：原生 JavaScript（ES Module）+ HTML5 Canvas 2D。禁止 React/Vue/Phaser/
   PixiJS/Babylon/Three 等任何运行时框架；禁止 npm 依赖；禁止打包步骤
   （无 webpack/vite/rollup）；禁止 CDN 外链（离线双击 index.html 必须能跑）。
2. 所有图片、音频资源必须由代码在运行时生成（程序化像素绘制 + WebAudio 合成），
   不加载任何外部 png/mp3/字体文件。唯一允许的外部资源是由用户后续手动放入
   /assets/sprites/ 的可选替换贴图，缺失时自动回退到程序化绘制。
3. 单页应用：index.html + /src/ 下的 ES Module 文件。可直接部署 GitHub Pages。
4. 内部分辨率固定 480×270（16:9），整数倍放大到屏幕，四周黑边 letterbox；
   canvas 使用 image-rendering: pixelated，禁止插值糊化。
5. 逻辑帧率固定 60Hz，用「固定时间步长 + accumulator」跑逻辑，渲染插值可选；
   掉帧时逻辑不加速、不减速。
6. 目标设备：中端安卓（骁龙 6 系）+ iOS Safari 15+。稳定 60fps，
   单帧逻辑耗时 < 4ms，粒子数上限 200。

【必须实现的玩法系统】
1. 2D 对战：左右移动、前冲、后撤、跳跃（起跳 12f / 总滞空 44f / 重力 0.32）、
   蹲防、站防、受身、击倒起身。
2. 判定框系统：每帧由 hitbox / hurtbox AABB 数组判定，全部数据驱动（JSON 表），
   禁止把判定框硬编码进绘制函数。攻击只在 active 帧生效，同一招式同一次出招
   对同一目标最多命中 1 次（多段技用 hitId 递增）。
3. 帧数据完整性：每招必须标注 startup / active / recovery、伤害、命中硬直、
   防御硬直、推开距离、是否中段/下段/不可防、是否击倒、取消窗口。
4. 攻防规则：按住「后」为防御；下段必须蹲防，跳跃攻击为中段必须站防；
   投技不可防且对蹲姿同样生效；破防值满则破防硬直 20f。
5. 连段与取消：轻攻击命中可取消为 重攻击 → 必杀 → 超必杀；
   连段伤害递减 100%/90%/80%/70%/60%（下限 30%）；浮空追打上限 3 段。
6. 命中停顿（hitstop）：轻击 6f、重击 10f、必杀 12f、超必杀 20f；
   命中瞬间双方冻结，受击方额外抖动 2px×2f，配合屏幕轻微震动与白闪。
7. 能量槽：0–100。命中 +2、被击 +3、防御 +1；必杀消耗 25，超必杀消耗 100。
8. 回合制：三局两胜，每回合 99 秒倒计时；KO / 时间到按剩余血量判胜；
   KO 时进入 0.25 倍速慢动作 1 秒 + 镜头推进 + 胜者胜利姿态。
9. AI 对手：状态机 + 反应延迟（8–14 帧）+ 四档难度参数
   （进攻频率 / 防御率 / 反制率 / 连段长度），禁止用"读帧完美防御"作弊式实现。
10. 游戏流程状态机：loading → title → modeSelect → charSelect → fight → pause
    → roundEnd → result → title。

【6 名角色】
全部为原创「光之战士」变体：保留该类型作品的通用视觉语言（紧身战斗服、
胸口/额头能量计时器、发光双眼、头冠鳍片、银白基底色），但在名称、配色、
计时器形状、头冠造型、胸甲纹样、体型比例、招式命名上全部原创差异化，

六个角色的定位必须两两不同：均衡型 / 牵制型 / 突进型 / 奇袭型 / 投技型 / 重装型。

【10 只怪兽】

【移动端与输入】
1. 强制横屏：竖屏时全屏显示遮罩"请将手机横置"，图标 + 文字 + 呼吸动画；

2. 全屏：右上角全屏按钮，调用 requestFullscreen()，全屏后才尝试锁定方向。

   - 按钮布局避开刘海与手势条安全区（env(safe-area-inset-*)）

4. 键盘映射（桌面端调试）：A/D 移动、W 跳、S 蹲、J/K 轻/重、L 必杀、空格 暂停。
